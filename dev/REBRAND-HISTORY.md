# إعادة تسمية الموقع: من "أكاديمية القراصنة العرب" إلى "OJ Flash"

هاد الملف بيوثّق **كل تعديل** تم تطبيقه على نسخة الموقع المبنية (built output — فرع `gh-pages`)
يلي رفعتها، عشان يكون عندك مرجع كامل، وعشان تقدر تطبّق نفس التعديلات على **الكود المصدري
الحقيقي** للمشروع (غالبًا موجود بمكان تاني غير هاد الفرع — شوف قسم "ملاحظة مهمة" تحت).

---

## ⚠️ ملاحظة مهمة قبل ما تبلش

فرع `gh-pages` يلي رفعته هو **ناتج بناء (build output)** — يعني ملفات جاهزة، مو الكود
الأصلي. لاحظت جوا الأرشيف مجلد فاضي اسمه `code-path-bloom-main` (فيه بس `.gitignore`
و `.nojekyll`)، وهاد بيدل إنو المشروع الحقيقي (React + Vite) مبني بمكان تاني — غالبًا
على منصة زي Lovable، أو على فرع `main` بنفس الريبو، أو بريبو منفصل.

**يعني:**
- التعديلات يلي عملتها هون (بهاد المجلد) **شغالة وجاهزة للنشر فورًا** — إذا رفعتها عالفرع
  `gh-pages` بتشوف الموقع الجديد على طول.
- بس إذا رجعت تعمل build جديد من الكود المصدري الأصلي (من Lovable أو من `main`)، هاد
  الـ build الجديد رح **يمسح** تعديلاتك ويرجع الاسم القديم، لأنك ما عدّلت المصدر نفسه.
- **الحل:** استخدم البرومبتات يلي بهاد الملف (قسم 8 وقسم 10) واعطيها للـ AI يلي شغال
  معك على الكود المصدري (Lovable / Claude Code / أي أداة تانية) عشان يطبّق نفس
  التغييرات هناك.

## 3. الألوان — من أخضر/بنفسجي إلى أزرق بالكامل

كل متغيرات الألوان (CSS variables) بملف `assets/index-BhPYGXCl.css` اتغيرت:

| المتغير | القديم (Hue/Sat/Light) | الجديد | الوصف |
|---|---|---|---|
| `--primary` / `--foreground` / `--ring` / `--neon-green` | `156 100% 50%` (أخضر نيون) | **`205 100% 55%`** (أزرق سماوي) | اللون الأساسي بكل الموقع |
| `--secondary` / `--accent` / `--neon-purple` | `271 76% 53%` (بنفسجي) | **`228 70% 58%`** (أزرق نيلي/إنديغو) | اللون الثانوي |
| `--border` / `--input` | `156 50% 20%` | **`205 50% 20%`** | لون الحدود |
| `--muted-foreground` | `156 30% 60%` | **`205 30% 65%`** | النص الخافت |
| `--neon-blue` | `195 100% 50%` | **بدون تغيير** (بقي نفس الأزرق السماوي، مستخدم بمستوى "متقدم") |
| `--destructive` (أحمر التنبيهات) | `0 84% 60%` | **بدون تغيير** (تركته أحمر بقصد، عشان رسائل الخطأ تبقى واضحة) |

النتيجة: كل التدرجات، الظلال النيون (`shadow-neon-*`)، والـ gradients صارت أزرق/نيلي
بدل أخضر/بنفسجي تلقائيًا لأنها كلها بتعتمد على نفس المتغيرات.

> هاد التدرج الأزرق (`205` سماوي + `228` نيلي) هو **الأساس** يلي بنيت عليه توجيه
> التصميم الجديد لكل صفحة بقسم 9 تحت — كل صفحة بتستخدم نفس العائلة اللونية، بس
> بطريقة مختلفة (تشبع/إضاءة/كثافة) حتى تحس إنها صفحة مميزة بذاتها.

## 9. توجيه التصميم — تصميم مختلف ومميز لكل صفحة

الموقع فيه 5 صفحات (routes):

| المسار | الاسم بالنافبار |
|---|---|
| `/` | الرئيسية |
| `/roadmap` | خارطة الطريق |
| `/practical-labs` | التطبيق العملي |
| `/tools` | مكتبة الأدوات |
| `/about` | حول |

بدل ما كل صفحة تكون "hero + كروت متل بعض"، كل صفحة تحت إلها **هوية تصميم خاصة فيها**
(تخطيط مختلف، استخدام مختلف للخط، بنية مختلفة) — بس كلهن مبنيين على نفس لوحة الألوان
الزرقاء (`--primary: 205 100% 55%` و `--secondary: 228 70% 58%`) ونفس خط الواجهة
(Tajawal)، ونفس الـ Navbar/Footer (الغلاف العام ما بتغير — التغيير جوا محتوى كل صفحة).

الشيء المشترك الوحيد المتكرر: **خط Monospace** (زي JetBrains Mono) يستخدم لأي محتوى
تقني (أوامر، أكواد، بيانات نظام) — بس بكثافة مختلفة كليًا من صفحة لصفحة (من صفر
بصفحة "حول"، لأقصى كثافة بصفحة "الأدوات").

### 9.1 الرئيسية `/` — "تسلسل إقلاع النظام" (Boot Sequence)

- **الفكرة:** الصفحة الرئيسية هي بوابة الدخول، فلازم تحس فيها بلحظة "تشغيل نظام"
  حرفيًا — مبنية على نفس فكرة `system.init()` الموجودة أصلاً بالكود، بس مأخوذة
  لحدها الأقصى كتجربة دخول.
- **التخطيط:** شاشة كاملة (full-viewport hero)، محاذاة **مركزية**. خلفية الجزيئات
  المتحركة (canvas) موجودة أصلاً، بتضل. فوقها: الشعار يضهر بالنص، وتحته سطر
  Monospace بيكتب حرف-حرف زي طرفية حقيقية (`> OJ_Flash_Academy.init()...`)، وبعدين
  العنوان الكبير يضهر. تحت العنوان: 3 أرقام إحصائية (عدد الأدوات، عدد المسارات،
  التقييم) مفصولين بخط رفيع عمودي — **مو كروت**. زر نداء واحد بس، واضح وكبير.
- **الخط:** العنوان الرئيسي بأكبر مقاس بالموقع كامل، Tajawal ExtraBold. سطر
  الإقلاع بـ Monospace بمقاس صغير فوق العنوان.
- **الحركة:** حركة واحدة منسقة بس (تسلسل الإقلاع عند تحميل الصفحة) — مو hover
  effects متفرقة على كل عنصر.
- **مخطط تقريبي:**
  ```
  ┌───────────────────────────────┐
  │      (خلفية جزيئات متحركة)      │
  │           [⚡ الشعار]            │
  │    > OJ_Flash_Academy.init()   │
  │      أكاديمية عمر الجزاع        │
  │    من الصفر إلى الاحتراف        │
  │        [ ابدأ الرحلة ]         │
  │   120+ أداة │ 40 مسار │ ★ 4.9  │
  └───────────────────────────────┘
  ```

### 9.2 خارطة الطريق `/roadmap` — "العمود الفقري" (Spine Timeline)

- **الفكرة:** هاي الصفحة الوحيدة يلي فيها فعلًا محتوى متسلسل (مرحلة 1، 2، 3...)،
  فهي المكان الصح لاستخدام أرقام/مؤشرات مرحلية (numbered markers) — لأن المحتوى
  فعلًا sequence، مو ديكور.
- **التخطيط:** خط عمودي واحد ("العمود الفقري") على **يمين** الصفحة (لأن الاتجاه
  RTL)، كل مرحلة عبارة عن نقطة متصلة فيه، والمحتوى يمتد يسارًا منها. المراحل
  الرئيسية نقطة كبيرة + عنوان بمقاس أكبر، والمواضيع الفرعية جوا كل مرحلة نقطة
  أصغر وعنوان أصغر متفرع عن الخط الرئيسي — مو كل شي نفس الحجم.
- **الخط:** رقم المرحلة بـ Monospace (`01`, `02`...)، عنوان المرحلة Tajawal Bold،
  ومقاس العناوين يكبر تدريجيًا كل ما نزلنا بالمراحل (إيحاء بالتقدم/النمو).
- **مخطط تقريبي:**
  ```
                          ●── 01  الأساسيات
                          │
                     ○─────┤  (مواضيع فرعية، أصغر ومتفرعة)
                          │
                          ●── 02  الشبكات
                          │
                          ●── 03  اختبار الاختراق
                          ⋮
  ```

### 9.3 التطبيق العملي `/practical-labs` — "طاولة العمل" (Split Workbench)

- **الفكرة:** صفحة عملية/تطبيقية، فلازم تحس فيها إنك قاعد قدام بيئة عمل حقيقية
  (IDE/Terminal)، مو صفحة تسويقية.
- **التخطيط:** تقسيم عمودي لعمودين. **يمين (ثابت/sidebar):** قائمة المختبرات
  بستايل شجرة ملفات/طرفية (`$ ls labs/`، `├─ recon`، `├─ network`...).
  **يسار (المحتوى الرئيسي):** تفاصيل المختبر المختار — عنوان ووصف بستايل "صفحة
  توثيق (man page)"، وتحته نافذة طرفية وهمية (نقط ملونة بالأعلى متل نافذة macOS)
  فيها مثال أوامر ونتيجة متوقعة.
- **مستوى الصعوبة:** بدل ما نجيب لون جديد، بنستخدم **درجة إضاءة مختلفة من نفس
  الأزرق**: مبتدئ = أزرق فاتح جدًا، متوسط = الأزرق الأساسي، متقدم = نيلي غامق.
- **الخط:** الوصف بـ Tajawal، كل شي جوا نافذة الطرفية بـ Monospace (أعلى كثافة
  Monospace بالموقع كامل بعد صفحة الأدوات).
- **مخطط تقريبي:**
  ```
  ┌───────────┬─────────────────────────┐
  │ $ ls labs │  تحليل حزم الشبكة          │
  │ ├─recon   │  ───────────────────────  │
  │ ├─network │  الوصف والهدف من المختبر... │
  │ ├─web     │  ┌─ ● ● ●  terminal ───┐  │
  │ └─crypto  │  │ $ wireshark -k      │  │
  │  [مستوى]  │  │ ...output...         │  │
  │           │  └──────────────────────┘  │
  └───────────┴─────────────────────────┘
  ```

### 9.4 مكتبة الأدوات `/tools` — "صفحة توثيق مرجعية" (Docs Catalog)

- **الفكرة:** هاي صفحة مرجع/كتالوج، مو صفحة تسويقية — المستخدم جاي يدور أداة
  محددة بسرعة، مو يتصفح بصريًا. فالتصميم لازم يكون **كثيف ومنظم**، مو كروت
  وظلال (بالعكس تمامًا من صفحة الأدوات القديمة يلي كانت شبكة كروت).
- **التخطيط:** عمود جانبي (يمين) فيه فهرس التصنيفات (OSINT، شبكات، تحليل جنائي
  رقمي...) + خانة بحث بالأعلى. المحتوى الرئيسي (يسار): قائمة الأدوات كإدخالات
  متتالية مفصولة بخطوط رفيعة (مو صناديق) — كل إدخال: اسم الأداة + سطر وصف واحد
  + أمر تنفيذي بصندوق Monospace + رابط خارجي. **بدون ظلال، بدون بوردر-راديوس
  موحّد على كل شي.**
- **الخط:** أصغر مقاس خط بالموقع كامل (صفحة مرجعية = كثافة معلومات، مو
  عرض/تسويق)، وأعلى استخدام Monospace بكل الموقع (كل أمر تنفيذي).
- **مخطط تقريبي:**
  ```
  ┌──────────┬───────────────────────────────┐
  │ 🔍 بحث    │  OSINT                         │
  │ ────────│  ─────────────────────────────  │
  │ OSINT    │  GHunt — أداة OSINT لحسابات Google│
  │ الشبكات  │  $ ghunt email user@gmail.com   │
  │ الأدلة   │  ─────────────────────────────  │
  │ الرقمية  │  Holehe — التحقق من 120+ موقع    │
  │ الويب    │  $ holehe email@example.com     │
  └──────────┴───────────────────────────────┘
  ```

### 9.5 حول `/about` — "سرد شخصي هادئ" (Quiet Editorial)

- **الفكرة:** هاي أكتر صفحة "إنسانية" بالموقع (بتحكي قصة عمر)، فبالعكس من كل
  الصفحات التانية التقنية/الكثيفة، هاي لازم تكون **الأهدى والأبسط** — الهدوء
  نفسه هو الاختيار المميز يلي بيفرقها عن باقي الصفحة.
- **التخطيط:** عمود واحد بعرض قراءة مريح (~65 حرف)، محاذاة مركزية، مسافات
  عمودية واسعة. اقتباس عمر الشخصي ("تم إطلاق هذه الأكاديمية بتوفيق من الله...")
  ياخد **أكبر مساحة بصرية بالصفحة** (مو مدفون بفقرة عادية) وكأنه العنوان الرئيسي.
  تحته اسمه ووصف قصير، وتحته قائمة بسيطة (مو كروت، مو أيقونات بصناديق) للشهادات
  والمسار، كل عنصر مفصول بخط رفيع تحته بس.
- **الخط:** أكبر مقاس نص أساسي (body) بكل الموقع (للراحة/الدفء)، الاقتباس بوزن
  Tajawal ExtraBold بمقاس عرض كبير. **الصفحة الوحيدة بدون Monospace نهائيًا** —
  إشارة إنها "صفحة إنسان" مو "صفحة نظام".
- **مخطط تقريبي:**
  ```
           ⚡

    "تم إطلاق هذه الأكاديمية بتوفيق من الله
     ومجهود متواضع مني..."      ← اقتباس كبير، محاذاة مركزية

         عمر الجزاع
    طالب هندسة تقنية معلومات، جامعة دمشق

    ───────────────────────
    الشهادات والمسار
    • شهادة 1
    • شهادة 2
    ───────────────────────

       [LinkedIn]   [GitHub]
  ```

### لخّص الفروقات

| الصفحة | المحاذاة | البنية المميزة | كثافة Monospace |
|---|---|---|---|
| الرئيسية | مركزية | تسلسل إقلاع + إحصائيات بخط فاصل | متوسطة (سطر واحد) |
| خارطة الطريق | يمين (spine) | خط متصل + مؤشرات مرحلية | منخفضة (أرقام فقط) |
| التطبيق العملي | تقسيم عمودين | طرفية وهمية + شجرة ملفات | عالية |
| مكتبة الأدوات | تقسيم عمودين (كثيف) | فهرس + قائمة مرجعية بلا كروت | الأعلى بالموقع |
| حول | عمود مركزي ضيق | اقتباس كبير + قائمة بسيطة | **صفر** |

## 10. البرومبت الجاهز — تنفيذ تصميم كل صفحة

انسخ النص التالي كامل واعطيه لأي AI (Claude Code, Lovable, ChatGPT...) عندو وصول
مباشر لكود المشروع المصدري. الأفضل تنفذه **صفحة-صفحة** (تحط بس القسم يلي بده ياها
بكل مرة) بدل ما تطلب كل الصفحات دفعة وحدة، حتى تقدر تراجع كل صفحة قبل ما تكمل:

```
بدي منك تعيد تصميم صفحات هاد الموقع (React + Vite + Tailwind CSS)، بحيث كل صفحة
تاخد هوية تصميم مختلفة عن الصفحة يلي قبلها، بس كلهن يبقوا مبنيين على نفس نظام
الألوان الأزرق الحالي (--primary: 205 100% 55%، --secondary: 228 70% 58%،
--neon-blue: 195 100% 50%) ونفس خط الواجهة (Tajawal). لا تغيّر الـ Navbar ولا
الـ Footer — هدول ثابتين بكل الصفحات، التغيير فقط بمحتوى كل صفحة (route).

أضف خط Monospace للمحتوى التقني (استخدم "JetBrains Mono" عبر Google Fonts أو
مكتبة موجودة بالمشروع لو في).

نفّذ كل صفحة حسب المواصفات التالية بالضبط:

── الصفحة الرئيسية (/) ──
حوّلها لتجربة "إقلاع نظام" (boot sequence):
- Hero بمحاذاة مركزية على كامل الشاشة، خلفية الجزيئات المتحركة الموجودة تبقى.
- فوق العنوان الرئيسي، أضف سطر بخط Monospace يكتب حرف-حرف عند تحميل الصفحة
  (typing effect) نصه "> OJ_Flash_Academy.init()..." ثم يظهر العنوان الرئيسي
  بعده مباشرة.
- تحت العنوان: 3 إحصائيات (عدد الأدوات، عدد المسارات، التقييم) معروضة بشكل
  مضمّن (inline) مفصولة بخط عمودي رفيع (border-right) — بدون أي بطاقات
  (cards) أو صناديق حولها.
- زر نداء واحد فقط (CTA)، واضح وكبير.
- حركة الإقلاع تصير مرة وحدة عند تحميل الصفحة فقط، بدون أي hover animations
  إضافية على العناصر.

── خارطة الطريق (/roadmap) ──
حوّلها لتصميم "عمود فقري" (spine timeline):
- خط عمودي واحد متصل على الجانب الأيمن من منطقة المحتوى (بما إن الموقع RTL).
- كل مرحلة رئيسية = نقطة كبيرة على الخط + عنوان بمقاس كبير، والمحتوى يمتد
  لليسار من النقطة.
- أي مواضيع فرعية جوا المرحلة تظهر كنقاط أصغر متفرعة عن الخط الرئيسي بشكل
  مائل بسيط (indented)، بعنوان أصغر من عنوان المرحلة.
- رقم كل مرحلة (01, 02, 03...) بخط Monospace صغير، وعنوان المرحلة بخط
  Tajawal Bold، ومقاس عنوان كل مرحلة يكبر تدريجيًا بمقدار بسيط كل ما تقدمنا
  بالمراحل (إيحاء بالتقدم).
- لا تستخدم بطاقات متطابقة لكل مرحلة — الحجم والتفرّع يعكس تسلسل/هرمية
  المحتوى الفعلي.

── التطبيق العملي (/practical-labs) ──
حوّلها لتصميم "طاولة عمل منقسمة" (split workbench):
- تقسيم الصفحة لعمودين: عمود جانبي ثابت (يمين) بعرض تقريبي 250-300px بستايل
  شجرة ملفات/طرفية (مثال: "$ ls labs/" ثم قائمة المختبرات كمسارات ملفات:
  "├─ recon"، "├─ network"، "└─ web")، وعمود رئيسي (يسار) يعرض تفاصيل
  المختبر المختار حاليًا.
- بالعمود الرئيسي: عنوان ووصف المختبر أعلى الصفحة بستايل نظيف يشبه صفحة
  توثيق (man page)، وتحته نافذة طرفية وهمية (mock terminal) — بورد رفيع
  ونقط ملونة صغيرة أعلى النافذة (تحاكي نافذة macOS)، وجوها مثال أوامر
  ونتيجة متوقعة بخط Monospace.
- مستوى الصعوبة لكل مختبر (مبتدئ/متوسط/متقدم) يتلون بثلاث درجات إضاءة من
  نفس اللون الأزرق الأساسي (فاتح جدًا للمبتدئ، اللون الأساسي للمتوسط، نيلي
  غامق للمتقدم) — بدون إدخال ألوان جديدة خارج العائلة الزرقاء.

── مكتبة الأدوات (/tools) ──
حوّلها من شبكة بطاقات لصفحة توثيق مرجعية (docs catalog):
- عمود جانبي (يمين) ثابت (sticky) فيه: خانة بحث/فلترة بالأعلى، وتحتها فهرس
  التصنيفات (OSINT، شبكات، أدلة جنائية رقمية، ويب...).
- المحتوى الرئيسي (يسار): قائمة الأدوات كإدخالات متتالية مفصولة بخطوط رفيعة
  أفقية (border-bottom) — بدون بطاقات، بدون ظلال، بدون استدارة زوايا موحّدة.
  كل إدخال: اسم الأداة (عنوان صغير) + سطر وصف واحد + صندوق أمر تنفيذي بخط
  Monospace (خلفية مختلفة قليلاً عن خلفية الصفحة) + رابط خارجي بسيط.
- هاي أكثر صفحة كثافة معلومات بالموقع: خط أصغر من باقي الصفحات، تباعد أسطر
  أقل، ومساحات فارغة أقل من أي صفحة تانية.

── حول (/about) ──
حوّلها لتصميم سردي هادئ (quiet editorial):
- عمود واحد بعرض قراءة محدود (تقريبًا 650-700px)، محاذاة مركزية، مسافات
  عمودية سخية بين العناصر.
- اقتباس عمر الشخصي (النص الموجود حاليًا اللي يبدأ بـ"تم إطلاق هذه
  الأكاديمية بتوفيق من الله...") يظهر بأكبر مقاس خط بالصفحة (أكبر من العنوان
  نفسه لو لزم)، بخط Tajawal ExtraBold، وكأنه هو العنصر الرئيسي بالصفحة —
  مو فقرة عادية جوا بطاقة.
- تحت الاقتباس مباشرة: اسمه ("عمر الجزاع") ووصف قصير (الجامعة والتخصص).
- تحته قائمة بسيطة (بدون أيقونات بصناديق، بدون بطاقات) للشهادات/المسار،
  كل عنصر مفصول بخط رفيع تحته بس.
- بالأسفل: زرين بسيطين للتواصل (LinkedIn وGithub).
- هاي الصفحة الوحيدة بكامل الموقع اللي ما فيها ولا حرف واحد بخط Monospace،
  وما فيها أي عنصر تقني/نظامي — الهدف إحساس إنساني هادئ يخالف باقي صفحات
  الموقع التقنية.

قبل ما تبدأ التنفيذ، اعرض علي خطة تصميم مختصرة لكل صفحة (فقرة أو فقرتين لكل
صفحة) للمراجعة. بعد ما أوافق، نفّذ صفحة وحدة بكل مرة وخذلي screenshot أو
وصف واضح لشكلها قبل ما تكمل عالتالية. تأكد إن كل صفحة متجاوبة (responsive)
لغاية الموبايل، وإن الـ Navbar والـ Footer ما تغيروا.
```

## 11. كيف تشغّل الموقع محليًا (localhost)

بما إنو الموقع تطبيق React (SPA) وفيه مسارات مطلقة (`/assets/...`)، ما رح يشتغل
منيح لو فتحت ملف `index.html` مباشرة بدبل-كليك من المتصفح — لازم "سيرفر محلي"
بسيط. في حالتين حسب شو عندك:

### أ) عندك بس ملفات الموقع الجاهزة (الـ build — متل الملف يلي أعطيتك ياه)

بعد ما تفك الضغط عن الملف:

```bash
cd rebrand
python3 -m http.server 8080
```

وبعدين افتح بالمتصفح:

```
http://localhost:8080/academy/
```

⚠️ افتح مسار `/academy/` تحديدًا (مو `/` الجذر) — لأنو `index.html` بجذر
المشروع مبني ليشتغل بس بعد النشر الفعلي على GitHub Pages (بيتوقع مسار
`/academy/` جاهز على نفس الدومين). نسخة `academy/index.html` هي يلي بتشتغل
صح محليًا مباشرة.

بديل لو ما عندك Python بس عندك Node.js:

```bash
npx serve .
```

### ب) عندك الكود المصدري الكامل (React + Vite project)

لو حصلت الكود المصدري الحقيقي (من Lovable أو ريبو `main`)، شغّله هيك:

```bash
# ثبّت الاعتماديات (أول مرة بس)
npm install

# شغّل سيرفر التطوير (بيفتح تلقائيًا على رابط محلي مع Hot Reload)
npm run dev
```

بعد الأمر التاني رح يطلعلك بالتيرمينال رابط زي:

```
Local: http://localhost:5173/
```

افتحه بالمتصفح، وأي تعديل عالكود بينعكس مباشرة بدون ما تعيد تشغيل السيرفر.

لما تخلص وتحب تعمل نسخة نهائية جاهزة للنشر (زي يلي عملتلك ياها بهاد المحادثة):

```bash
npm run build
```

رح يطلعلك مجلد `dist/` (أو `build/` حسب إعدادات المشروع) فيه نفس نوع الملفات
يلي شفتها بهاد التسليم (`index.html`, `assets/*.js`, `assets/*.css`...) وجاهز
ترفعه عالفرع `gh-pages`.
